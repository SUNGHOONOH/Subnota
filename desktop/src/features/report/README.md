# Report

## 역할

월간 메모·일정 활동을 요약하고, 사용자별 읽음 표시를 관리한다.

## 월간 리포트 상태

`useMonthlyReport`는 열림 상태, 보고 있는 달, 읽음 처리한 달과 리포트 계산을
소유한다. 실제 데이터 생성 알고리즘은 `monthlyReport.ts`에 유지한다.

## 외부 의존성

읽음 표시는 브라우저 localStorage에 사용자별로 저장한다. Supabase, Backend API,
SQLite에는 직접 접근하지 않는다.

## 불변 조건

- 리포트 기준 월은 현재 진행 중인 달이 아닌 직전 달이다.
- 이번 달 메모가 최소 기준을 넘고 아직 읽지 않았을 때만 배지를 표시한다.
- 리포트를 열면 현재 사용자 owner 기준으로 읽음 상태를 저장한다.

## 관련 테스트

- `src/__tests__/monthly-report.test.ts`

## Windows 주의사항

리포트 계산은 렌더러 메모리의 데이터만 사용한다. 파일 접근이나 동기 네트워크
요청을 추가하지 않는다.
